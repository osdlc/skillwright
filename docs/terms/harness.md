# Harness

Status: current.

A coding-agent tool skillwright builds for: Claude Code, Codex, Cursor and Pi.

## In code

The `Harness` enum in `harness/profile.rs`; `Harness::profile` gives its row of data.

## Not to be confused with

A [target](target.md), which is a harness's name as `build.harnesses` or `--harness` spells it. `agent-adapt` calls a harness a runtime.
