# Field reference

Generated from the key table in `tradecraft-core`. Do not edit this file: run `TRADECRAFT_BLESS=1 cargo test -p tradecraft-core --test field_reference` from `packages/rust`.

The kind of a note comes from its folder. A key not listed for a kind gets a warning and is never refused. Owner `skillwright` means the key is read into the model and stripped at publish, and takes the prefix under `build.namespace`. Owner `spec` means the key belongs to the Agent Skills spec or a harness, and is never prefixed. An inherited key comes from the nearest container that sets it: the plugin note, then `skillwright.md`, then the workspace.
