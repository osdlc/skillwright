# Standards

One record per standard. A standard is a spec that tools and data follow. It is rewritten in place
while it is at version 0. Ids are random keys, so parallel branches do not collide.

| Id                              | Standard                                                   |
| ------------------------------- | ---------------------------------------------------------- |
| [S-GFFY](S-GFFY-markdown-db.md) | markdown-db, version 0: typed records as files in a folder |

Terms are defined in [../terms](../terms/README.md). Decisions are in [../decisions](../decisions/README.md).
