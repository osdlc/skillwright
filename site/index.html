Write a skill once.
Ship it to every agent.

skillwright is a command-line tool for coding-agent skills. You keep each skill as a markdown note in a vault. skillwright publishes the notes into the formats of Claude Code, Codex, Cursor and Pi, and tells you when the output has drifted.

$ brew install osdlc/tap/skillwright

Also on npm, crates.io and as a curl installer; see all install options. macOS and Linux.

my-project
# one note in a vault
$ cat my-vault/skills/code-review.md
---
description: Reviews a diff for correctness bugs.
---
Read the diff. Report each bug with the line and a fix.

$ skillwright list --vault my-vault

01

How it works

One source of truth. Each harness gets the files it expects. A check tells you when they stop matching.

VAULT

Write notes

A vault is a folder of markdown notes. Each skill, plugin or marketplace is a note with frontmatter. new, adopt, move and rename author and reorganise the vault; rename rewrites every link to the renamed note.

BUILD

Render per harness

publish writes notes to their destinations. build renders the vault into its marketplace roots and swaps them into place. --dry-run shows the plan first.

CHECK

Catch drift

check reports the marketplace's drift against the vault. It writes nothing and exits 1 on drift, so it fits in CI. status shows each note's state at each destination.

02

Supported harnesses

Four coding-agent tools today. Each gets its own on-disk format.

HarnessPublish & buildHooksharness install
Claude Codeyesyesyes
Codexyesyesyes
Cursoryesyesyes
Piyesnono

Hooks are written once as a Claude Code hooks.json. build renders them in each harness's shape and writes a gap report of anything a harness cannot carry. harness install registers the built marketplace through the harness's own plugin command.

03

Install

macOS and Linux, arm64 and x86_64. Windows is not supported yet.

Homebrewosdlc/tap
brew tap osdlc/tap
brew trust osdlc/tap
brew install osdlc/tap/skillwright
npm@osdlc/skillwright
npm install --global @osdlc/skillwright
# or run it once
npx @osdlc/skillwright --help
cargocrates.io
cargo install skillwright
# or fetch the prebuilt binary
cargo binstall skillwright
install.shGitHub Release
curl -fsSL https://github.com/osdlc/osdlc/releases/download/skillwright/v0.3.7/install.sh | sh

install.sh checks the binary against the release's SHA256SUMS and installs to ~/.local/bin, or to the folder given with --to. The tool was renamed from tradecraft in 0.3.7; the release notes list what to rename.
