# skillwright site

The landing page for [skillwright](https://github.com/osdlc/skillwright), the CLI that
publishes a vault of markdown skill notes into the formats of Claude Code, Codex, Cursor and Pi.

It is one static file, `index.html`, with inline CSS and no scripts, fonts or
CDNs. Open it in a browser to view it. It follows the system light or dark
theme and works at phone width.

The CLI source currently lives in
[osdlc/osdlc](https://github.com/osdlc/osdlc/tree/main/packages/rust/skillwright)
and is moving to this repository. Check the install commands against the README
of the tool when a channel changes.

## Files

- `index.html`: the page.
- `screenshots/`: desktop (1440px) and phone (390px) captures in light and
  dark.
